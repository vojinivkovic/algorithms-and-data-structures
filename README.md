# Algorithms and Data Structures

A C++ implementation of a **weighted directed graph** used to represent a lexical knowledge base.

## Features

- Dynamic adjacency-matrix graph representation
- Adding and removing vertices and edges
- Weighted directed edges
- Path finding using propagated edge weights
- Finding the `k` most semantically similar words
- Strong connectivity analysis
- Graph loading from files and interactive input
- Custom dynamic stack implementation

## Algorithms

- Depth-first search
- Graph transpose
- Strong connectivity analysis
- Path reconstruction
- Weighted path propagation

## Academic Context

Developed as part of university coursework.

## Technologies

- C++
- Graph algorithms
- Data structures
- Dynamic memory management
